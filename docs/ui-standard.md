# Canvas UI 标准

本文约束当前微信小游戏单 Canvas 界面的布局与交互。尺寸均为平台提供的逻辑像素；Canvas 的 DPR 缩放不能再次乘到布局坐标上。`safeTop` 是顶部安全区的结束坐标，`safeBottom` 是底部安全区的开始坐标。

## 顶部栏

顶部控件位置与尺寸的唯一来源是 `src/ui/top-bar-layout.js`。主题只改变颜色、图像和棋盘外观，不改变顶部栏位置。切换场景时，同一侧的顶部控件应保持在同一水平线上。

| 项目 | 当前标准 |
| --- | --- |
| 顶部触控区 | 48 × 48，顶边 `safeTop + 12`，中心 `safeTop + 36` |
| 左右边距 | 左侧 `x = 16`；右侧距屏幕右边 16 |
| 图标 | 居中绘制，尺寸为触控区短边的 0.48，即约 23；图标不等于触控区 |
| 主页头像 | 48 × 48 的入口与触控区，头像图片在圆形区域内留 2 像素内边；资料卡中的大头像另属内容区 |
| 主页右侧状态 | 体力区宽 64、货币区宽 62–78，均高 48；货币与体力留 6 像素间隔；金币左侧圆圈“i”公告入口为 48 × 48，间隔 6，极窄视口移到金币下方 |
| 标题 | 页面标题的垂直中心与顶部控件一致；关卡编号、选关和画廊标题也遵循此规则 |
| 次级文字 | 选关和画廊页码位于标题中心下方 26；普通关计时下方 25；每日挑战详情下方 28 |

各场景左侧顶部入口：主页为 `home:account`，资料页为 `account:back`，选关页为 `levels:home`，普通关为 `play:back`，每日挑战为 `daily:home` / `dailyResult:back`，回廊为 `corridor:home`，主题和特效页使用各自的返回 action。普通关与每日挑战的右上角重置也使用相同 48 × 48 区域；声音控制位于账号页游戏设置的音量滑条。返回、主页和重置图形的视觉尺寸相同，不因为场景不同而放大触控区。

未授权时的微信原生资料按钮属于头像下方的独立操作：左边与头像对齐，顶边为头像触控区底部再加 8，高 38，宽度不超过 160。它不能覆盖头像或被误当成顶部栏第二个图标。

## 内容与状态

- 顶部标题和两侧控件不得重叠；窄屏标题按两侧 48 像素触控区之间的可用宽度缩放或截断，不能挤占命中区域。
- 主页主操作按钮高 54，并以 `safeBottom` 计算纵向位置。资料卡、选关网格、主题与特效卡片、棋盘及结果面板在各自内容区排布，不靠改变顶部栏偏移量获取空间。
- 触控矩形就是实际注册的 hit 矩形；禁用状态不应留下可点击的旧命中区域。按下态、文字和图标仍使用当前主题的语义色，不在布局模块写死主题颜色。
- 图片加载失败时，主页头像显示默认人像；资料页使用已有占位。头像内容可比顶部图标大，触控区和中心线仍按统一标准。
- 横竖屏和安全区变化后，重新从当前 `platform.metrics` 计算位置。不得用截图像素或固定设备型号校正顶部栏。

## 版本更新面板

新版首次启动的更新面板与主页圆圈“i”图标 `home:updates` 共用展示；打开后清空画布，使用不透明主题底色加整屏深色层覆盖上下安全区，主页图案、按钮及状态提示均隐藏；关闭后恢复完整主页。只注册 `update:confirm`，确认后恢复主页命中区。打开时卸载微信原生资料授权按钮，关闭后恢复。三个简短更新条目按实际宽度换行，结果面板定位、字号和确认按钮均受安全区约束；双语和横屏验证见 [版本更新面板](update-notice.md)。

## 账号页分区

`src/ui/account-layout.js` 统一提供分区、内容行与命中区几何；`CanvasRenderer.drawAccount()` 只消费布局和当前主题语义色。

- “用户资料与存档”卡片包含头像、昵称、账号说明及云存档状态；备份模式下的备份和恢复操作也在此区域。
- “游戏设置”卡片包含语言选择和消除方式切换，两行均使用左侧标签与右侧“上一项箭头／当前值／下一项箭头”，箭头位置对齐；只有箭头注册命中区。消除方式默认同时消除，依次消除为可选；已有合法存档值继续保留。消除方式通过 `account:clearMode:prev` / `account:clearMode:next` 循环切换，原 `account:clearMode` action 保留兼容但不再注册整行命中区；存档协议不变。
- 消除方式下方为音量行，左侧标签、右侧滑条与百分比；`account:volume` 只在右侧控制区注册至少 44 像素高的命中区。布局同时提供 `volumeRow`、`volumeControl`、`volumeTrack`，App 与 Renderer 共用几何；主触点独占拖动，越界位置限制到 0–100%。拖动立即试听，松手一次保存；取消、离开、后台或尺寸变化恢复已确认值，异步保存期间暂停新的拖动。主页不绘制或注册 `home:sound`，旧声音 action 继续兼容。
- 隐私协议为卡片之外的独立底部入口；独立 App 已有的恢复购买入口继续共用底部操作区。
- 竖屏上下排列两个区域，横屏左右排列。依据当前安全区压缩间距与资料摘要，常用窄屏及横屏保留至少 44 像素的设置触控高度；异常短视口才继续压缩高度以保持全部操作可见。

## 验证

`tests/level-ui.test.js` 在 280、320、390 宽及不同 `safeTop` 下检查跨场景中心线、48 × 48 命中区、左右控件、标题和原生资料按钮位置；`tests/account-layout.test.js` 另覆盖窄屏、高安全区及横屏资料页，检查两类内容所属区域、独立隐私入口和备份模式。修改布局后运行 `node tests/run.js` 与 `git diff --check`，并在微信开发者工具和真机预览窄屏、较高顶部安全区、授权按钮及实际触控。自动化坐标检查不能代替设备视觉验收。
