## 数据与机制边界

- 题面追加到 `data/clearedset8.json`，运行模块由 `node scripts/generate-level-modules.js` 生成；显示顺序只向 `data/level-order.js` 的尾部添加坐标。没有重排 `Games`。
- 普通／冰封完整解答按新 ID 追加到 `data/ordinary-chapter-solutions.js`；Portal 分段解答追加到 `data/portal-solutions.js`。50 个中英文名称使用同一稳定 ID 的词典键，游玩标题仍为数字进度。
- 每条普通线路 4–16 格，冰封 4–18 格，Portal 4–20 格；同色端点不相邻，无主导整盘的单一路线。普通格完整覆盖一次，冰格由两条不同线路各覆盖一次。
- 十个 Portal 均为一个 `P1` 双门网络、`portal@2` 和一条真实双段线路；禁门精确求解全部为 `unsatisfiable`，状态上限 250,000，没有用搜索限额代替无解证明。
- 十个冰封沿用 `ice@1`：七题 8 格、三题 12 格，2–3 个四邻接冰区；没有端点冰、门格冰、三层冰或新机制版本。
- 新题与全部既有 8×8 及本批其他题按八种旋转／镜像和颜色重标记去重；作者预览按题面与解答检查。设计等级依赖官方解的结构估计，仍须玩家试玩校准。
