## 每日挑战与混合棋盘

每日内容见[十天机制包](daily-mechanic-pack.md)及其后的[未来四周关卡包](daily-four-week-pack.md)。纯冰封题保持 `Mechanic: ice`；混合题以 `Mechanic: portal`、`PortalRulesVersion: 2` 为主机制，附加 `IceRulesVersion: 1` 和 `IceCells`，不新增复合机制 ID。只支持这一明确组合，不把机制任意组合化。

混合棋盘的只读机制状态在 Portal 状态中附加 `ice: { id, rulesVersion, cells }`。Portal 的入口锁定、等待出口和续接本身不消耗冰；只有整条线路完成后才更新层数。两层由两条不同连线消耗，撤销/重置沿用相同快照。每日题面校验失败时拒绝进入，不以普通棋盘替代。

纯冰封与混合每日题均用已有手动分步提示（箭头或左右滑动），没有 10 秒自动关闭；提示仍须通过每日提示许可，不改变真实棋盘、次数或奖励。

## 规则合同

- `Mechanic: 'ice'`、`IceRulesVersion: 1`；试玩 `IceCells: [12]`，主线 `IceCells: [9]`。
- 冰封只允许声明在空白可走地板上，不能与端点、Blocked 或 Portal 重叠。
- 普通格需要一次成功连接，冰封格需要两次：第一次只破冰，第二次才消除地板。
- 两次来自两条完整线路；同一条线路拖回旧格仍然是回退，不是第二次消耗。
- 选中、取消、未连接成功均不消耗冰；重画原线路会移除其旧贡献，不能反复刷掉第二层。
- 撤销、重置、系统取消按原有快照边界恢复。剩余层数由已提交线路重建，不另存一份增减日志。
- 必须完成所有同色连接，且所有必填格的剩余层数为零才通关。全部端点连接完但地板仍在则失败。
- 未知版本、非数组、重复／越界／非整数索引、端点／Blocked／传送门格冲突或 Portal v1 混用整份拒绝激活冰封，
  运行时安全回退普通规则；试玩 opener 额外确认实际启用了冰封后才进入。

v1 每格上限是一层冰加一层地板；第 138 关曾作为单格教学接入，不是把玩法限制为一格。
2026-09-08 已追加六个多冰格主线题及四个普通题，完成对应评分与独立回归；详见 [十关过渡包](thaw-level-pack.md)。
冰格可连续或分散，本批 2–12 格不是运行时上限，规则版本仍为 1；三层以上、同一路线自交、除 Portal v2 外的其他机制组合或实时求解不在本次范围。

## 表现与提示

冰封格使用普通地板上的半透明浅蓝白薄冰、切角亮边和少量边缘裂纹。
选中时保持线路颜色可辨识；不添加数字、不移动触摸中心、不改变格子几何。
「逐渐消失」下第一次连接使用短暂冰片淡出，底层地板保留；「无特效」下冰层立即移除。
第二次连接沿用普通消除效果。全部为 Canvas 绘制，无新增纹理图片或分包资源。

棋盘上方复用现有 32px 提示带，分两行显示：

> 冰封格需要两次连线  
> 第一次破冰，第二次消除地板

试玩的「提示」免费、不限次，不走每日免费次数、分享或广告授权。
点击后从初始题面的第 1 步开始，分四步展示线路：

1. 红线通过中央冰封格，说明「经过冰封格，先破冰」。
2. 红线已清除、中央保留普通地板，显示蓝线路径，说明「再次经过，消除地板」。
3. 中央格已消除，显示黄色线路。
4. 显示绿色线路。

左右滑动或点击左右箭头手动切换；左滑下一步、右滑上一步，第一页／末页禁用对应箭头，
不循环翻页。横向位移超过 52 且大于纵向位移的 1.2 倍才翻页，竖滑、小幅移动、touchcancel 不翻页。
右侧箭头之间显示 `1/4`（试玩）或 `1/9`（主线）等步骤数，复用选关页 Canvas 箭头及 44px 点击区域。
新多冰格关卡按实际线路数显示页数；同一步既破冰又清除已破冰地板时显示“破冰并消除已解冻地板”，避免只说明其中一种效果。

这是手动解答预览，不是自动代玩；不自动切步，也不在 10 秒后关闭。点击「隐藏提示」恢复玩家原棋盘；
预览中棋盘输入、重置、回撤被拦截，计时规则不变。非冰封的普通、Portal 和每日的完整解答显示及
提示资格规则不改变。完整解答在展示前校验端点、四邻接、其他端点冲突、单线重复、
普通格一次／冰格两次的覆盖计数，非法或不完整预设不显示。

## 代码边界

- `core/mechanics/ice-v1.js`：版本策略与纯声明校验；由 core allowlist 选择。
- `core/game-runner.js`：唯一玩法权威；重建剩余层数、占用与胜负，通过只读查询供外层消费。
- `src/mechanics/ice.js`：声明式名称、版本与试玩内容依赖；不携带运行回调。
- `src/gameplay/run-context.js`、`completion-policies.js`：来源决定主线普通结算或试玩无存档结算，不能按 ice 机制推断。
- `src/services/hint-service.js`：试玩 ID 读取试玩解答，主线冰封按稳定 ID 读取主线解答，再交同一个 ice provider 校验。
- `src/services/hints/ice-hint-provider.js`：只消费纯 HintContext，复用普通四邻接解答校验，
  输出已校验线路及逐步展示快照，不持有 Runner、Canvas 或平台。
- `src/app.js`：入口、纯棋盘 ViewModel、预览生命周期、破冰动画快照与结算边界。
- `src/ui/board/ice-overlay.js`、`board-renderer.js`：冰层／冰片绘制；不推导业务胜负。
- `src/ui/canvas-renderer.js`：试玩标题、两行说明、手动提示选帧／箭头和结果按钮。
