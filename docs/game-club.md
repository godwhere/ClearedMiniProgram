# 游戏圈接入与运营

## 当前状态

主页已移除游戏圈入口，不再创建 `wx.createGameClubButton` 原生图标。玩家头像保留为账号入口；其下方仅在资料未授权时显示微信原生资料按钮，与游戏圈无关。

以下保留后续重新接入游戏圈时的运营准备，不表示本次发布包含有游戏圈入口。微信官方的[游戏圈指南](https://developers.weixin.qq.com/minigame/dev/guide/open-ability/game-club.html)和[按钮接口文档](https://developers.weixin.qq.com/minigame/dev/api/open-api/game-club/wx.createGameClubButton.html)是平台行为依据。

若以后使用 `wx.createPageManager`，需先在微信公众平台游戏圈“基础设置”取得本 AppID 的首页 `openlink`，或从帖子／话题列表取得对应链接。不要猜测或复用别的游戏的链接；重新接入时须补充失败回退与设备验证。

## 微信后台与正式运营

1. 用本游戏的小游戏账号进入微信公众平台 **功能 → 游戏能力地图 → 游戏圈**，按后台页面完成游戏圈开通、官方号及运营权限设置。
2. 在游戏圈用官方号发布至少 5 篇真实、与本游戏相关的官方帖，并在后台核对“官方帖子数据”。实际内容、审核及计数以该 AppID 后台为准。
3. 如决定重新提供游戏圈入口，将带入口的小游戏版本上传、提审并发布。用正式微信客户端确认进入的是本游戏的圈子；再由真实用户自然产生圈内行为，并查看后台“内置圈子有效活跃”。开发者工具的模拟点击和本地测试不能形成这个条件。
4. 回到 **功能 → 流量主** 查看当前 AppID 的资格状态。截图中的条件二要求“内置游戏圈有效活跃”与“5 篇官方帖”同时满足；客户端接入、发帖数量和真实活跃分别核对，不能由代码推断资格。若申请页要求同意服务协议，由账号负责人阅读并自行决定。

可供正式发布后审核使用的五篇官方帖草稿：

1. **欢迎来到 Cleared 游戏圈**：这里可以交流通关思路、反馈问题，也欢迎分享最喜欢的关卡。Cleared 的目标很简单：连接同色端点，并让每一个格子都被路径覆盖。你现在玩到了第几关？
2. **新手连线小技巧**：连线只能沿上下左右相邻格子走，不能穿过别的端点或已有路径。遇到卡住的棋盘，可以先观察边缘和角落，再决定哪条线先走。你有哪些有效的小技巧？
3. **传送门关卡怎么玩**：路径进入传送门后会暂停，松手后从同一网络的另一个出口继续。它依然要和其他颜色一起覆盖整张棋盘。欢迎交流你是如何判断入口和出口顺序的。
4. **冰封格挑战**：冰格需要由两条不同的完整连线先后经过，才能完成破冰和清除。试着先规划两种颜色的路线，再处理普通空格。哪一关的冰封布局最让你印象深刻？
5. **每日挑战交流区**：每日挑战包含热身和正式挑战，适合用不同于主线的节奏练习。完成后可以来分享你的解题思路；请尽量用文字描述关键步骤，方便其他玩家参与讨论。

这些只是待审核文案，不是已发布的官方帖。发帖前核对届时的正式版本、可见功能和平台内容规范，不承诺奖励、付费或尚未上线的内容。

截至 2026-09-30，本仓库未保留游戏圈入口；后台游戏圈是否已开通、官方帖数量、真实活跃、流量主资格和真机跳转均未验证。不要据本地代码宣称流量主已开通。
